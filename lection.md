# Ethernet коммутатор

### Таблица коммутации:
- содержит таблицу MAC-адресов и интерфейсов
- заполняется **обучением** - каждый новый запрос пополняет таблицу
- каждая запись имеет TTL
- первый шаг - broadcast сообщение на все порты

## VLAN

**VLAN** - virtual local area network

VLAN на основе портов - порты коммутатора группируются так, что один физ. коммутатор
работает как несколько логических, и внутри одного VLAN клиенты общаются напрямую (если надо выти за пределы VLAN,
то **надо общаться по IP, не по MAC**)

**Trunk port** - магистральный порт - передает по сетям VLAN, охватывающим множество физ. коммутаторов

## STP / SRTP

Он строит дерево для определения пути и избегания путей в сетях между коммутаторами

* Root Bridge - корневой мост - главный коммутатор (от него дерево строим)
* Root Port - порт коммутатора, который участвует в построении дерева на входе
* Dst Port - порт коммутатора, который участвует в построении дерева на выходе

Процесс построения дерева классический достаточно

Мы начинаме строить дерево, и как только видим, что где-то шагов стало больше, чем шагов до dst, мы  там обрываем dst порт.

* В STP при перестроении топологии происходит новое перестроение
* В RSTP же только локальное перестроение 

Есть также еще TRILL, но он не сильно взлетел

## Многопротокольная коммутация по меткам (MPLS)

* Коммутация не по IP адресам, а по спец. меткам фиксированной длины
* Быстрый поиск

MPLS где-то между Ethernet и IP
